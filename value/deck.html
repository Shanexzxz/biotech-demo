01

Core value

AI 的价值有两层：提升运行效率，更重要的是放大认知生产能力

近端价值，是减少重复工作、压缩协同与交付周期；更深层的价值，是提升机构获取信息、验证假设、调用经验、形成判断和管理资产的整体能力。

运行效率带来即时收益，认知能力决定长期差异。前者让机构运转得更顺畅，后者让单位专业人员能够调用更多知识、处理更多有效信息并形成更高质量的判断。

01 / COVERAGE

扩大信息覆盖

持续处理新闻、政策、论文、公司材料、访谈纪要、交易和投后经营信息。

02 / EFFICIENCY

提升运行效率

压缩研究、分析、汇报与协同周期，减少重复录入、材料整理和标准化运营工作。

03 / MEMORY

沉淀组织记忆

让历史项目、专家访谈、IC 观点和投后经验成为可以重新调用的机构知识。

04 / QUALITY

增强判断质量

通过证据追溯、跨文件验证、情景推演和反方论证减少遗漏与逻辑跳跃。

四个基本判断效率带来即时收益，认知能力决定长期差异——价值兑现的逻辑建立在这四句话上

01 / MODEL

模型不是壁垒

大模型能力持续提升、价格持续下降，任何机构都能订阅同样的智能。竞争优势已从「是否拥有智能」转移到「能否用好智能」。

02 / CONTEXT

专有 context 是原材料，持续积累才是壁垒

同一个模型，喂公开信息给出人人可得的答案；喂机构多年积累的判断历史与产业语境，才可能产出有机构印记的洞察。把持续积累的资产与可替换的模型分开建设，模型每换代一次，既有积累就跑在更强的引擎上。

03 / WORKFLOW

组织方式决定效果，工作流与行动决定价值

个人零散使用 AI，有效方法与工作语境容易停留在个人层面；嵌入正式工作流，产出才成为机构资产。AI 扩大机构看、想、记、持续跟踪的能力；人负责定义问题、理解语境、作出判断、建立关系、采取行动并承担责任。设计的重心不是「AI 能生成什么」，而是「哪个判断、哪个行动会因此改变」。

04 / EVALUATION

评测与反馈决定是否真正进化

每一次 AI 辅助的判断被记录并复盘，有效的做法固化、无效的淘汰，机构才真正在学习。价值的验证按证据逐层递进：从效率提升，到流程质量，到决策与行动的真实改变，再到经营与投资结果——不把工具使用直接当作投资回报。

02

Capability reality · tool division

AI 已能参与研究全流程——关键是分清它与确定性工具的分工

当前 AI 工具已经能够参与资料检索与整理、跨来源分析、文档和表格处理；接入适当的数据与工具后，还可以协助完成多步骤研究、建模和运营任务。三类工作值得现在就开展验证。

01 / MATERIALS

处理已有材料

在范围明确的文件与数据中提取信息、归纳观点、比较差异、整理证据和起草材料——团队集中核验关键内容。

02 / ANALYSIS

围绕问题组织分析

拆解任务、检索信息、关联支持与反对证据、调用表格与计算工具，形成供专业人员检验的分析结果。

03 / ALWAYS-ON

接入流程持续运行

数据来源、触发规则和负责人明确时，定期更新信息、检查变化、整理提醒与待办，让工作保持连续。

工具分工：灵活的分析 × 可核验的执行

AI 承接

理解非结构化材料、关联信息、生成分析与调用工具。

确定性系统承接

金额计算、业绩指标、日期提醒和审批状态，由明确的计算规则、数据库与流程工具完成。

落地条件各不相同：材料整理与初稿生成可较快验证；持续情报、跨项目知识调用与报告同源取数，需要接入数据并明确流程；经验复用与投资结果的改善，需要长期积累与验证。

03

Near-term priorities · proposed

近期建议：从高频、易验证的组合视图与会前准备切入

以下为建议的试点顺序，尚未成为已批准或已启动的机构安排。首批围绕少量资料较完整的项目或一个明确业务范围开展，控制建设范围。

01 / PILOT

主试点：组合视图

合伙人项目与组合视图，配套本期变化简报——验证能否更快掌握项目与组合情况、定位值得追问的问题、推动后续行动。

02 / COMPANION

轻量配套：资料与会前

同一批项目的机构资料检索、会前简报与追问——验证历史判断是否更易调用、会前准备是否更高效。

03 / NEXT

后续扩展：情报监测

与重点项目和投资假设关联的外部情报监测——验证重要变化是否更及时进入研究、判断与投后讨论。

速赢如何长成长期能力

递进路径

整理必要资料 → 持续使用与反馈 → 保留数据与判断依据 → 沉淀可复用方法 → 扩展更多场景。

推进方式

专人协调口径、组织反馈；早期人工核验、半自动更新；不承诺全组合实时监控。

切入条件：已有较稳定的项目台账和投后报表，先做组合视图；数据口径尚不统一而研究材料与会议纪要较完整，则先从会前简报与资料追问切入。

04

Fundraising · investing · managing · exiting

AI 场景全景：募、投、管、退，每个阶段都有可被重构的工作

参考 Coatue、SignalFire、Moonfire、EQT、Earlybird 以及医疗方向 RA Capital、Foresite 的公开实践，AI 的机构价值并非集中在投研，而是贯穿资金、项目、资产和机构经营的完整循环。

01 / FUNDRAISE

募

LP 市场与目标地图

连接 LP 类型、配置偏好、历史出资、关键关系和策略匹配度，辅助目标分层与触达顺序。

基金定位与募资叙事

把策略、团队、行业观点、组合构建、差异化能力和市场窗口转化为一致叙事。

业绩、归因与案例材料

连接基金／项目回报、估值变化、投资与退出案例，形成 PPM、数据室和 Track Record 支撑材料。

DDQ 与定制问答

从底层资料生成初稿、定位证据、识别缺口，并针对不同 LP 关注点准备会议简报。

Pipeline、关系与成交管理

沉淀会谈、异议、承诺、材料需求和下一步动作；维护 CRM、认购进度、KYC 及交割事项。

持续 IR 与下一期募资

生成季度报告、估值解释、组合更新和定制回复，并保持底层数据、历史披露与对外口径一致。

例：会前自动组合某 LP 的配置偏好、历史问题和最相关案例；会后更新异议、资料需求和跟进动作。

公开参照：EQT Investor Portal 强调下一代投资者服务；Moonfire Launchpad 展示结构化 Fundraising CRM 的应用方式。

02 / INVEST

投

行业研究与 Thesis

持续追踪政策、技术、论文、专利、融资、交易和竞争格局，把变化转为影响、假设与行动。

项目发现与弱信号

组合招聘、人才迁移、产品、流量、客户、合作、股权和人物网络，识别早期机会。

初筛与历史比较

提取团队、产品、客户、融资和财务事实，匹配相似项目、投／弃原因及管理层验证问题。

智能尽调与证据索引

跨合同、订单、财务、回款、法务和运营数据核验口径，分析集中度、续约、Cohort 与异常。

IC、估值与组合构建

连接逻辑与证据，形成 Bull／Base／Bear Case、反方论证、敏感性和基金层面的配置判断。

交易执行与决策留痕

追踪条款、先决条件、补充材料和审批事项，将最终判断、分歧及证据沉淀为机构记录。

医疗场景可进一步连接疾病机制、分子／靶点、临床试验、监管、医生患者、支付与市场准入证据。

公开参照：Coatue Mosaic／Brain 连接研究与知识；SignalFire Beacon 用于机会发现；RA TechAtlas 将科学证据转为投资判断；Foresite 让投资分析师、MD／PhD 与数据科学家协同覆盖医疗全生命周期。

03 / MANAGE

管

经营监测与主动预警

综合预算、Pipeline、客户、产品、组织、现金、融资、舆情、诉讼和竞争动态识别领先信号。

投前假设与董事会闭环

持续检验投资逻辑是否成立，追踪董事会问题、关键承诺、风险处置与后续行动。

价值创造计划

VC 关注增长、组织和关键客户；PE 深化定价、采购、营运资本、销售效率与 EBITDA 改善。

人才、客户与生态支持

进行关键人才搜索、客户／渠道匹配、市场扩张、合作伙伴识别和跨组合资源连接。

融资与资本配置

更新现金消耗、融资窗口、跟投与储备策略，比较不同资金方案对项目和基金回报的影响。

医疗专项运营

追踪临床方案、试验进度、患者招募、监管路径、CMC、供应商和同类管线数据。

例：收入增长但转化率、回款和现金安全边际恶化时，系统同步触发客户质量、预算、融资和成本方案。

公开参照：Beacon Talent／GTM 支持人才和市场；EQT Motherbrain 服务价值创造；RA Blackbird 将跨组合经验用于临床开发。

04 / EXIT

退

退出准备度诊断

持续评估业绩质量、组织稳定性、合规、审计、数据完整性和关键风险是否满足退出要求。

买方、Sponsor 与合作方图谱

连接战略逻辑、业务互补、历史交易、关键关系和潜在协同，动态维护优先买方名单。

市场窗口与可比交易

追踪资本市场、估值水平、监管变化、同类交易和买方动作，识别更合适的退出时点。

退出情景与回报推演

比较 IPO、并购、股权转让等路径，并测算不同时间、估值、稀释和交易结构下的回报。

卖方材料与交易问答

提前组织经营证据、价值创造结果、数据室、管理层问答和潜在风险处置方案。

归因、LP 叙事与经验回流

解释回报来源和关键转折，将退出结果反馈到募资案例、投前假设和下一轮资产管理。

医疗退出还需连接临床与监管里程碑、管线差异化、潜在药企战略缺口和合作／收购逻辑。

公开参照：Earlybird EagleEye 明确覆盖价值创造与潜在收购方；RA TechAtlas 以大型药企视角绘制策略图，支持合作与退出判断。

落地场景、提升与承接载体：投前看得更广，想得更深——所有场景遵循同一原则：嵌入正式工作流、与人充分互动、依据反馈持续优化

真正的机构级能力，不是让某一个环节多一个工具，而是让募投管退共享数据、知识、工作流与反馈。

05

Memory · workflow · evaluation

机构化的三个支柱：记忆资产化、流程正式化、检验驱动迭代

当前各环节并非没有使用 AI——问题在于个人化、分散化的使用沉淀不下机构能力。有价值的记录被保留、校验和复用后，才形成积累——这是「机构化」与「买工具」的根本区别。

01 / MEMORY AS ASSET

让经验不再流失：把机构记忆变成资产

经验成为可检索、可复用的机构资产，而不是随人员流动而流失的个人记忆。

  1. 投资判断全程留痕。每个项目从立项起记录「当时怎么判断、依据什么、后来结果如何」。
  2. 机构认知持续在线。产业、人才、科研网络的结构化积累由日常研究持续喂养；外部重要信号自动关联到受影响的项目与持仓。
  3. 专家打法可以传承。资深合伙人与骨干的研究框架、提问方式、判断标准，沉淀为全团队可调用的模板与工具；管理层对材料的修改意见持续成为学习样本。
02 / AI IN WORKFLOW

让 AI 进入正式流程：而不是停留在个人工具

先做最痛的事，做出信任再扩展——不铺大摊子。

  1. 先做最痛的事。从需求最明确、见效最快的环节启动（如情报监测、IC 材料），做出信任再扩展。
  2. 每个应用都有责任人。每个工作流明确输入标准、产出形式、人工审核点与行动出口——不产生没人负责、没人行动的产出。
  3. 人先判断，AI 再挑战。关键岗位保留独立初判，再引入 AI 的反方视角；关键事实可追溯到原始来源；估值与预测由专业工具计算、可复算。
  4. 边界持续校准。哪些任务由 AI 主导、哪些人机协同、哪些必须人负责，随模型能力与验证证据动态调整。
03 / TEST TO ITERATE

让检验驱动迭代：工作流在真实反馈中持续进化

检验不是目的，迭代才是——每一次评估的终点，是工作流的下一个版本。

  1. 事前说清什么叫成功。每个试点启动前明确验证标准，达不到就停——不为创新而创新。
  2. 用真实使用说话。采纳还是忽略、接受还是驳回，从实际使用痕迹中评估价值，不看供应商演示。
  3. 定期复盘，据以迭代。对照当初的假设检验 AI 的真实贡献：有效的做法固化为流程，无效的调整或淘汰。
  4. 用自己的问题检验工具。以机构真实研究任务建立内部评测基准，模型与工作流的每次升级都须证明优于上一版，否则回退。

三个支柱相互支撑：没有记忆资产化，AI 只能给出人人可得的答案；没有流程正式化，有效方法停留在个人层面；没有检验迭代，机构无法真正进化。

06

Explore · validate · compound

机构级价值来自持续的探索与验证，而不是一次工具选型

模型能力、数据条件和业务需求都在变化。把单点机会转化为可复用能力，需要持续完成一套从场景识别到效果复盘的闭环。

01 / PRIORITISE

发现并排序机会

持续观察业务痛点与模型能力，按价值、可行性和风险维护场景机会地图。

02 / PROTOTYPE

拆解并验证工作流

明确输入、判断节点、证据要求和人工环节，用真实材料快速构建原型。

03 / EVALUATE

评估质量与边界

检验准确性、证据追溯、遗漏风险、数据权限和实际使用体验。

04 / EMBED

嵌入并复盘沉淀

把有效能力连接到已有流程，跟踪效果并沉淀可复用标准与组件。

持续探索可以形成四类可复用产出

01

场景机会地图

看清哪些问题值得优先验证。

02

真实业务原型

用项目材料判断价值是否成立。

03

评估与风险标准

形成准确性、证据和权限边界。

04

可复用工作流

把有效方法沉淀为机构能力。

当这些工作被持续完成，AI 才会从若干单点工具，逐步成为可复用、可验证、可迭代的机构能力。

07

Dynamic human–AI boundary

人机边界不是一条固定线，而是一项需要持续完成的机构工作

哪些工作交给 AI、哪些必须由人负责、哪些最适合协同，不宜靠一次工具选型或制度设定决定。随着模型能力、数据条件、风险认识和团队使用方式变化，最优边界也会持续移动。

01 / AI-LED

适合由 AI 主导

  • 大规模阅读、提取、分类与格式转换；
  • 跨文件比较、证据定位和异常识别；
  • 常规监测、材料初稿与数据更新；
  • 规则清晰、结果可复核的重复流程。
02 / COPILOT

适合人机协同

  • 行业研究、项目初筛与管理层问题设计；
  • 尽调核验、情景推演与 IC 准备；
  • 投后预警、退出分析和 IR 材料；
  • AI 提供证据与选项，人完成复核、判断和行动。
03 / HUMAN-LED

必须由人负责

  • 识人、建立关系和理解隐性动机；
  • 谈判、利益协调与复杂博弈；
  • 信息不足时形成非共识判断；
  • 关键对外沟通、受托责任与最终决策。

边界探索需要持续完成四类工作

01 / TRACK

跟踪能力变化

持续理解模型、工具、数据连接、安全能力和行业实践出现了哪些新可能。

02 / TEST

用真实材料试验

在投资、IR、投后和运营工作流中验证质量、效率、使用体验与实际限制。

03 / CALIBRATE

校准分工与护栏

根据证据、准确性、权限和风险，判断由 AI 主导、人机协同还是人负责。

04 / UPDATE

更新最优运行状态

把有效方法嵌入流程，复盘使用与业务结果，并随能力演进持续调整。

动态边界清单

明确每类任务当前最适合的 AI、人机协同与人工责任位置。

评价与治理标准

形成证据、准确性、权限、保密、审批和异常处理要求。

机构适配方案

沉淀适合本机构的数据、工具、工作流和协作方式，并持续更新。

目标不是尽可能多地使用 AI，而是随着能力演进，持续找到最适合本机构的人机分工、工具组合与运行状态。
08

Evidence · layered verification

成效按证据分层核验——不把工具使用直接当作投资回报

能力潜力、建设进度和已实现成效应当分别说明；有成效证据时，再说明改善发生在哪一层。

01 / EFFICIENCY

效率

同类任务的总耗时、人工核验与返工负担、交付周期及运行成本是否改善。

02 / PROCESS

流程质量

重要信息是否更及时进入讨论，来源是否更可追溯，关键遗漏与口径冲突是否减少。

03 / JUDGMENT

判断与行动

尽调问题、预测假设、投资安排、投后动作或服务方式是否发生了有依据的变化。

04 / OUTCOME

经营与投资结果

行动之后出现了什么结果，AI 辅助工作的贡献有多少证据支持，其他影响因素是什么。

早期先证明效率与流程质量，再积累说明判断与行动变化的记录；经营与投资结果周期长、影响因素多，需要持续观察。机构学习是否真正发生，看经验有没有进入后续工作、重复问题有没有减少。

Conclusion / 结论

模型能力决定可做任务的边界，机构化整合决定实际使用效果

Replaceable Models. Proprietary Context. Persistent Learning Loop.

  1. 模型不是壁垒；
  2. 专有 context 是原材料；
  3. 人与 AI 的组织方式决定效果；
  4. 工作流与行动决定价值；
  5. 评测与反馈决定是否真正进化；
  6. 持续吸收新技术的能力决定长期竞争力。

这六句话，就是机构全部 AI 建设投入的收益逻辑。AI 能为机构带来的提升，不取决于使用了什么模型，而取决于机构是否拥有把智能转化为判断与行动的组织能力。
